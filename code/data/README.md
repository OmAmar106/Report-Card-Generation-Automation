## How To Use It

You can enter the Subject short form as key and the [subject full form, course code] as value in the data.json format
or you could enter it while running the code, it would get updated there as well.

In case you want to delete/update some pair, you will have to do so manually from data.json. 

Put the Control Sheet in this directory and then run the code from the directory in which you want the final file to be created,
the final file that will be created will have the format BranchName/Year/Files.
